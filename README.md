# Proyecto-5_Estudio-de-caso-de-economia

El salario sube, pero… ¿alcanza para más?

1. Planteamiento del caso

Este proyecto analiza si el aumento de los ingresos laborales entre diciembre de 2024 y diciembre de 2025 representó una mejora real para los trabajadores en Colombia. Para ello, se utilizan datos de la GEIH y se considera el efecto de la inflación, comparando el crecimiento nominal y real de los ingresos.

El análisis también permite identificar los grupos con menor evolución real de sus ingresos según sexo, nivel educativo y rango de edad.

2. Estructura del repositorio

-README.md: descripción del proyecto e instrucciones de ejecución.

-Actividad_5_¿Si_alcanza_más_la_plata?.ipynb: notebook con el análisis y los resultados.

-datos/base_2024.csv: base de datos correspondiente a 2024.

-datos/base_2025.csv: base de datos correspondiente a 2025

3. Instrucciones para ejecutar

-Descargar o clonar el repositorio.

-Abrir el archivo .ipynb en Google Colab o Jupyter Notebook.

-Cargar los archivos de datos requeridos.

-Ejecutar las celdas en orden.

-Utilizar el menú del programa para consultar los resultados por grupo y el resumen final.

Tecnologías: Python, Pandas, NumPy y Matplotlib.
